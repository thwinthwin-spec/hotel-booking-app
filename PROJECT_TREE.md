## 3. File-by-file purpose (grouped)

### 3.1 `server/config/`

| File | Purpose |
| --- | --- |
| `server/config/db.js` | `connectDB()` wrapper around `mongoose.connect`, using `MONGODB_URI` with a local default; exits with a clear error if connection fails |
| `server/config/cloudinary.js` | Configures Cloudinary v2 from `.env`; `uploadRoomImages(files)` converts Multer buffers to data URIs, uploads to `hotel-booking/rooms`, returns `secure_url` list |
| `server/config/stripe.js` | Exports a Stripe SDK client in test mode using `STRIPE_SECRET_KEY` |
| `server/config/email.js` | Backwards-compatible re-export of `server/utils/email.js` so callers can import from `config/` |

### 3.2 `server/controllers/`

| File | Purpose |
| --- | --- |
| `server/controllers/auth.controller.js` | `register`, `login`, `getMe`, `updateProfile`; bcrypt hashing/comparison and JWT issuance |
| `server/controllers/hotel.controller.js` | Hotel list (pagination/search/city), detail with populated rooms, create/update/delete |
| `server/controllers/room.controller.js` | Room list with all filters and availability dates, detail, create with Cloudinary uploads, update, delete |
| `server/controllers/booking.controller.js` | Booking creation with overlap check and price snapshot, my-bookings, owner/admin detail, cancel, admin list, status update |
| `server/controllers/payment.controller.js` | Stripe PaymentIntent creation, raw-body webhook verification and event handling, cash payment recording |
| `server/controllers/review.controller.js` | Review creation with owner/checked-out/uniqueness rules, room review listing |
| `server/controllers/admin.controller.js` | Dashboard aggregation and user role management |

### 3.3 `server/middleware/`

| File | Purpose |
| --- | --- |
| `server/middleware/auth.js` | Verifies `Authorization: Bearer <token>` and sets `req.user = { id, role }` |
| `server/middleware/role.js` | `authorize(...roles)` factory; `403` when the token role is not allowed |
| `server/middleware/upload.js` | Multer memory storage; images only, at most 5 files of 5 MB each |
| `server/middleware/validate.js` | Runs express-validator rules and emits the standard `{ message, errors }` `400` response |
| `server/middleware/errorHandler.js` | Translates CastError, duplicate key, validation and Multer errors into clean JSON |
| `server/middleware/notFound.js` | `404 { message: 'Route not found' }` fallback |

### 3.4 `server/models/`

| File | Purpose |
| --- | --- |
| `server/models/User.js` | Name, email, bcrypt password, phone, role enum, avatar, active flag; hides password via `toJSON` |
| `server/models/Hotel.js` | Hotel profile, images, rating, amenity refs, nested contact, creator ref; indexes on name and city |
| `server/models/Room.js` | Hotel ref, room number, type enum, price, capacity, amenities, images, inventory, availability; unique `{hotel, roomNumber}` index |
| `server/models/Booking.js` | User/hotel/room refs, dates, guests, computed price snapshot, status/payment enums, cancellation reason, overlap index |
| `server/models/Payment.js` | One payment per booking, amount/currency, Stripe intent id, status and method enums |
| `server/models/Review.js` | One review per booking, rating 1–5, comment, user and room refs |
| `server/models/Amenity.js` | Globally unique amenity name with icon and category |

### 3.5 `server/routes/`

| File | Purpose |
| --- | --- |
| `server/routes/index.js` | Combines all resource routers and mounts them under `/api` |
| `server/routes/auth.routes.js` | Register/login/me/profile paths and their validation chains |
| `server/routes/hotel.routes.js` | Public reads and admin-only write paths for hotels |
| `server/routes/room.routes.js` | Room reads, admin writes, and the `upload.array('images', 5)` middleware on create |
| `server/routes/booking.routes.js` | Guest and admin booking paths, ownership and role chains |
| `server/routes/payment.routes.js` | Create-intent, cash and the raw-body webhook route |
| `server/routes/review.routes.js` | Review creation and room review listing |
| `server/routes/admin.routes.js` | Dashboard and user role-management paths |
